## 📐 贡献指南

欢迎提交 PR 添加新项目!请遵循以下规范:

### 条目格式

```markdown
- [owner/repo](https://github.com/owner/repo) — 一句话描述(中文,40 字以内优先)
```

### 收录标准

1. **活跃维护** — 最近 6 个月内有 commit
2. **真实可访问** — 链接可达,非占位/空仓库
3. **描述准确** — 一句话说清楚"解决什么问题"或"和什么同类型",不要纯形容词堆砌
4. **星标数据** — 如标注 `⭐ xxk`,需附数据日期(如 `⭐ 46k (2026-05)`)
5. **不夸大不营销** — 避免"史上最强""宇宙第一""彻底颠覆"等表述

### PR 流程

1. Fork 本仓库
2. 在对应分类下按字母序插入新条目
3. 标题:`Add owner/repo to 分类名 category`
4. 一个 PR 一个项目,便于 review

### 不收录

- ❌ 纯营销/教程仓库(无代码)
- ❌ 已 archived 且无继任者的项目
- ❌ 重复功能的同一项目(如已收录官方版,不再收录 fork)
- ❌ 链接失效且无法找到替代
